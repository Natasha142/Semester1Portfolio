# Semester 1 Portfolio

### Project 1: Harry Potter Name Generator
***Summary***: This program allows the user to discover which Harry Potter Character fits their personality most closely.
**Key Features**: 
- Fetches information about the user.
- Displays the name of the user's Harry Potter counterpart. 
- Completely accurate 100% of the time.

  
### Project 2: MadLib

**Key Features**:

- Completely accurate 100% of the time.
